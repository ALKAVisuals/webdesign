# Lettertypen

- `bodoni-moda-variable.ttf` — redactionele titels en hoofdstukkoppen.
- `manrope-variable.ttf` — technische labels, lopende tekst en folio's.

Beide lettertypen komen uit de officiële Google Fonts-repository en vallen onder de SIL Open Font License. De bijbehorende licentieteksten staan in deze map.
