# Projectbeelden

## `de-houtkavel-projectintro.png`

Dit beeld is met de ingebouwde beeldgeneratie gemaakt als canonieke projectvisualisatie voor het ontwerpboek.

Kern van de gebruikte prompt:

> Een rustige, fotografisch geloofwaardige visualisatie van een eigentijdse Nederlandse woning met verticale houten gevel, donkere kozijnen en een lage woonvleugel in een natuurlijk weidelandschap. Zacht laat-middaglicht, ingetogen kleuren, echte materiaaltextuur, rechte geometrie en voldoende rustige crop-ruimte. Geen personen, auto's, tekst, collage, overdreven luxe, onmogelijke constructie of herkenbare AI-artefacten.

Nieuwe beelden voor hetzelfde project moeten architectuur, materiaalgebruik, landschap en kleurtemperatuur herkenbaar voortzetten.
